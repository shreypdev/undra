Your browser's clock rounds to 0.1 ms, so anything faster reads “< 0.1 ms”. Measured with a real clock, one change-set of 100 signals takes 2.3 µs.

Measured in your browser

A drain is the mirror applying what the core sent since the last frame to the local signals and notifying subscribers, timed with performance.now(). Browsers round that clock (Chrome to 0.1 ms, Firefox and Safari to 1 ms), so one drain faster than the step reads as “under” it. The average is a batch: every drain of the last two seconds, their times added up and divided by their number. Each reading is off by less than a step, too high or too low, and across a batch those errors even out, so the average is a real number below the step; it reads “under” only when the whole batch took less than one step. The slowest drain is one reading, so it is shown as a bound: under one step more than it read. Push it makes the core generate 10,000 updates a second on its own timer. The counters then also show how many it generated, how many entries the mirror applied after merging what arrived between two frames (and what share of those received), and the frames this page dropped, counted with requestAnimationFrame. Nothing here is a recording.

How these are measured

Medians from cargo bench (criterion, release, LTO). Budgets are the design's per-device targets; CI gates are regression guards about 5x the host median. Harsh-conditions cards: 10-second sustained runs on the host, core side, on a shared machine; their gates are floors at one fifth of the measured rate. Frame-coalesced delivery (ADR-031) leaves these core-side numbers as they are: what it changes is the platform-side apply, and the live demo above shows that, measured in your browser (Push it). Measured on Apple M5 Pro, 18 cores, macOS 26.5. Simulator, emulator and Chromium rows are in the benchmark results; real-phone rows are not claimed and are on the roadmap.

use undra::prelude::*;

/// One item of the to-do list.
#[undra::api]
pub struct Todo {
    pub id: Uuid,
    pub title: String,
    pub done: bool,
}

/// Why an item could not be added.
#[undra::error]
pub enum TodoError {
    #[error("the title cannot be empty")]
    EmptyTitle,
}

/// The to-do list: what every UI observes and calls.
#[undra::store]
pub struct Todos {
    #[undra(key = "id")]
    todos: Signal<Vec<Todo>>,
    filter: Signal<Filter>,
    #[undra(key = "id")]
    visible: DerivedList<Todo>,
    remaining: Computed<u32>,
}

#[undra::api(store)]
impl Todos {
    pub async fn add(&self, title: String) -> Result<Todo, TodoError> { /* … */ }
    pub fn set_filter(&self, filter: Filter) { /* … */ }
}

SwiftUI

TodosScreen.swift
// SwiftUI: Todos is @Observable. Reading a signal is a plain property read.
struct TodosScreen: View {
    let todos: Todos            // try Todos() after UndraPlaygroundCore.load()
    @State private var draft = ""
    @State private var problem: String?

    var body: some View {
        List {
            ForEach(todos.visible, id: \.id) { todo in
                Button { todos.toggle(id: todo.id) } label: {
                    Label(todo.title, systemImage: todo.done ? "checkmark.circle.fill" : "circle")
                }
            }
        }
        .toolbar {
            ToolbarItem(placement: .principal) { Text("\(todos.remaining) left") }
        }
    }

    private func add() {
        Task {
            do { _ = try await todos.add(title: draft); draft = "" }
            catch { problem = error.localizedDescription }   // TodoError, CancellationError or UndraCallError
        }
    }
}

Compose

TodosScreen.kt
// Compose: signals are StateFlows.
@Composable
fun TodosScreen(vm: TodosViewModel = viewModel()) {
    val store = vm.store
    val visible by store.visible.collectAsState()
    val remaining by store.remaining.collectAsState()

    Column {
        Text("$remaining left")
        LazyColumn {
            // keyed by id in the core, so Compose moves rows instead of redrawing them
            items(visible, key = { it.id }) { todo ->
                TodoRow(todo, onToggle = { store.toggle(todo.id) })
            }
        }
    }
}

// in the ViewModel
viewModelScope.launch {
    try { store.add(draft) }
    catch (e: TodoError) { /* TodoError.EmptyTitle */ }
}

React

TodosView.tsx
// React and React Native: hooks from @undra/runtime/react (vue, svelte and solid adapters ship too).
import { useUndra, useSignal } from "@undra/runtime/react";
import { Todos, TodoError } from "@playground/core";

export function TodosView() {
  const store = useUndra(Todos);            // undefined until it exists
  const todos = useSignal(store?.visible);
  const remaining = useSignal(store?.remaining);

  async function add(title: string) {
    try {
      await store?.add(title);
    } catch (error) {
      if (error instanceof TodoError) { /* a typed error, not a string to parse */ }
    }
  }
  /* … render todos, `${remaining} left` … */
}

Queries

core/src/remote.rs
/// The items of a server list, cached per list, fresh for 30 s, persisted.
#[undra::query(key = "remote-todos:{list}", stale = "30s", persist, retry = 1)]
pub async fn remote_todos(ctx: &Ctx, list: String) -> Result<Vec<RemoteTodo>, RemoteError> {
    let url = endpoint(ctx, &format!("/lists/{list}/todos"))?;
    parse(&send(ctx, HttpRequest::get(url)).await?)
}

/// Shows the item at once; takes it back if the server refuses.
#[undra::api]
pub async fn create_remote_todo(ctx: &Ctx, list: String, title: String) -> Result<RemoteTodo, RemoteError> {
    // …build `placeholder`…
    ctx.mutate::<PostRemoteTodoMutation>((list, title))
        .optimistic(move |cache| {
            cache.update::<RemoteTodosQuery>((cached,), |items| items.push(placeholder));
        })
        .await
}
