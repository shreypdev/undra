API reference

Swift reference

Every declaration undra bindgen generates in Swift for the playground (schema hash 0x3c17cd5f59bb6f68). The API overview explains how it is shaped.

Bodies, initializers, private and override members are left out, and a run of declarations that differ only by a number is folded to its ends. Each file name links to its complete source.

The core#

The core's entry, named after its namespace: load starts the core and checks its schema hash, and core is the one every generated call uses unless it is given another.

/// The core these bindings belong to, `playground_core` (`[core] namespace` in undra.toml): `load`
/// starts it, and `core` is the core every generated type and function of this module uses
/// unless it is given another one (`ctx:`).
///
/// ```swift
/// let core = try UndraPlaygroundCore.load() // linked into the app
/// let dev = try UndraPlaygroundCore.load(.remote(url: "ws://127.0.0.1:7878")) // `undra dev`
/// ```
public enum UndraPlaygroundCore {
    /// The core's namespace: it exports `playground_core_undra_api` from `libplayground_core.a`.
    public static let namespace = "playground_core"

    /// Loads the core (linked into the app unless `options` say otherwise) and makes it
    /// `core`. Throws `UndraSchemaMismatchError` when the core was built from another schema,
    /// and `UndraLoadError` when it cannot start or is already loaded.
    public static func load(_ options: LoadOptions = .inproc()) throws -> UndraCore

    /// The loaded core, or, while none is loaded (or after it was closed), a closed placeholder
    /// whose calls fail as unavailable.
    public static var core: UndraCore
}
