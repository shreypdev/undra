API reference

Kotlin reference

Every declaration undra bindgen generates in Kotlin for the playground (schema hash 0x3c17cd5f59bb6f68). The API overview explains how it is shaped.

Bodies, initializers, private and override members are left out, and a run of declarations that differ only by a number is folded to its ends. Each file name links to its complete source.

The core#

The core's entry, named after its namespace: load starts the core and checks its schema hash, and core is the one every generated call uses unless it is given another. The internal UndraCoreNative holds the natives the core's library registers over JNI.

/**
 * The core these bindings belong to, `playground_core` (`[core] namespace` in undra.toml): [load]
 * starts it, and [core] is the core every generated class and function of this package uses
 * unless it is given another one (`ctx`).
 *
 * ```kotlin
 * val core = UndraPlaygroundCore.load() // in this process
 * val dev = UndraPlaygroundCore.load(LoadOptions(Mode.REMOTE, remoteUrl = "ws://10.0.2.2:7878")) // `undra dev`
 * ```
 */
object UndraPlaygroundCore {
    /** The core's namespace: its library is `libplayground_core.so`. */
    const val NAMESPACE: String = "playground_core"

    /**
     * Loads the core (in this process unless [options] say otherwise) and makes it [core].
     *
     * @throws UndraSchemaMismatchException if the core was built from another schema.
     * @throws UndraException if it cannot start, or this core is already loaded.
     */
    fun load(options: LoadOptions = LoadOptions()): UndraCore

    /**
     * The loaded core, or, while none is loaded (or after it was closed), a closed placeholder
     * whose calls fail with `UndraCallError.Unavailable`.
     */
    val core: UndraCore get()
}

/**
 * What the app implements to hear from the core.
 *
 * The app implements it and passes it to the core, which keeps it until it lets go of it.
 * The core calls it on the main thread, in order with the stores' changes: a method sees
 * the stores as they were when the core called it.
 * [weak] wraps an implementation without keeping it alive.
 */
interface Reporter {
    /**
     * Asks whether to go on; the app may answer later, or not at all.
     * @throws ReportError to answer the core with an error; anything else it throws is
     *   reported (`LoadOptions.onError`) and the core is answered unavailable.
     */
    suspend fun confirm(question: String): Boolean

    /** A line to show. */
    fun note(line: String)

    /**
     * How far a job is: `done` of `total`. Only the newest report of a burst matters, so the
     * platforms deliver just that one to a listener that has fallen behind.
     */
    fun progress(done: UInt, total: UInt)

    companion object {
        /**
         * Forwards to [target] while something else keeps it alive, and holds it only weakly: once it
         * is collected, the methods that return nothing do nothing and the `suspend` ones answer the
         * core unavailable. For an implementation that holds, directly or not, the object it is passed
         * to (a view model that owns the store it listens to), which would otherwise keep itself alive.
         */
        fun weak(target: Reporter): Reporter
    }
}

/**
 * Observes the `feed` query (cache key `feed/{even_only}`).
 * Constructing it registers an observer and fetches when the data is stale or missing.
 * The query is paged: `data` grows by one page each time `fetchNextPage()` completes.
 */
class FeedQueryHandle internal constructor(core: UndraCore, handle: Long) : UndraStore(core, handle), InfiniteQuery {
    /** Every row loaded so far, in order: the first page, then each page `fetchNextPage()` loaded. Empty until the first page arrives. */
    val data: StateFlow<List<Item>>
    /** Where the query is in its fetch lifecycle. */
    val status: StateFlow<QueryStatus>
    /** The error of the latest failed fetch, cleared by the next success. */
    val error: StateFlow<ListError?>
    /** Whether a fetch is in flight (also true while refetching stale data). */
    val fetching: StateFlow<Boolean>
    /** When `data` was last updated. */
    val updatedAt: StateFlow<Timestamp?>

    /**
     * Fetches again now, even if the data is fresh.
     * A failure is logged and passed to `LoadOptions.onError`; the method does not throw.
     */
    fun refetch()

    /**
     * Marks the cached entry stale; it refetches while observed.
     * A failure is logged and passed to `LoadOptions.onError`; the method does not throw.
     */
    fun invalidate()

    /**
     * Overrides how often the query polls while this handle observes it, counted from the end of a fetch.
     * The entry polls at the smallest interval among its observers; no interval clears this handle's override.
     * An interval below 1 second or above 7 days is clamped to that range.
     * A failure is logged and passed to `LoadOptions.onError`; the method does not throw.
     */
    fun setPollInterval(interval: Duration?)

    companion object {
        /** @throws UndraCallError if the core panics, refuses or cancels the call, or cannot be reached. */
        operator fun invoke(
            evenOnly: Boolean,
            ctx: UndraCore = UndraPlaygroundCore.core,
        ): FeedQueryHandle

        /** @throws UndraCallError if the core panics, refuses or cancels the call, or cannot be reached. */
        fun create(evenOnly: Boolean, ctx: UndraCore = UndraPlaygroundCore.core): FeedQueryHandle
    }
}
